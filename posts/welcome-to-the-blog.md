Welcome! This blog is powered by **plain HTML, CSS, and JavaScript** with zero build steps or static-site generators required.

## How It Works

1. Add a new `.md` or `.html` file inside the `posts/` folder.
2. Register its title, date, summary, tags, and file path in `posts.json`.
3. Commit and push to GitHub — your new post is live on GitHub Pages.

## Markdown Features Supported

You can use standard Markdown formatting:

- **Bold**, *italic*, and `inline code`
- Headings (`##`, `###`) and horizontal rules (`---`)
- Ordered and unordered lists
- Blockquotes and fenced code blocks

> Simplicity makes it much easier to keep writing and publishing consistently.
