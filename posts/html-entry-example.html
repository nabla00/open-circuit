While Markdown covers most writing needs, sometimes you want direct control over markup. Any entry whose file ends in .html (or sets "format": "html" in posts.json) is rendered directly inside the article body.

When to Use HTML Posts

  • Custom tables, figures, or interactive embeds
  • Specialized typography or side-by-side comparisons
  • Migrating existing HTML notes without converting them to Markdown

Both .md and .html posts share the exact same dark theme stylesheet and search index.

Example Code Block

<!-- posts/my-custom-post.html -->
<h2>Custom Section</h2>
<p>Write any standard HTML fragment here.</p>
