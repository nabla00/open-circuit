Welcome! This site is built with **Jekyll**, which GitHub Pages runs automatically whenever you push to your repository.

## How It Works

1. Add a new `.md` or `.html` file inside the `_posts/` folder using the filename format `YYYY-MM-DD-post-title.md`.
2. Add three front matter fields at the top: `title`, `date`, and `description` (plus `layout: post`).
3. Commit and push — GitHub Pages compiles your Markdown into static HTML automatically.

> Even if a visitor turns off JavaScript completely, every post and the main listing still render as plain static HTML.

```yaml
---
layout: post
title: My Next Post
date: 2026-11-25
description: A short summary shown on the main page.
---
```
